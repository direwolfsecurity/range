Downloads

The download folder holds the databases in MaxMind's format, so standard tools read them: GeoLite2-City.mmdb, GeoLite2-Country.mmdb, GeoLite2-ASN.mmdb (plain and .gz), their SHA256SUMS and the registry.csv they were built from.

Make your web server geo-aware

curl -O http://@SERVER_NAME@/download/range-geoip-client.sh
sudo bash range-geoip-client.sh --apache --php --go   # or --nginx

Apache then gives every request variables like MM_CITY, MM_COUNTRY_CODE, MM_LATITUDE and MM_ASN. In PHP: $_SERVER['MM_CITY'].
